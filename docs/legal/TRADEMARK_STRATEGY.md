Status: trademark filing strategy and protection plan

## Pre-filing actions

### 1. Trademark search

Before filing, conduct comprehensive searches:

| Search | Purpose | Source |
| --- | --- | --- |
| USPTO TESS | US registered/pending marks | uspto.gov |
| EUIPO eSearch | EU registered/pending marks | euiropa.eu |
| UK IPO | UK registered/pending marks | gov.uk |
| WIPO Global Brand Database | International marks | wipo.int |
| Common law search | Unregistered mark usage | Web search, domain search |
| State trademark databases | US state registrations | Secretary of State websites |

### 2. Search targets

Focus on "Sovereign" marks in:
- IC 9: Computer software, mobile applications, AI software
- IC 42: Scientific/technological services, SaaS, AI services
- IC 44: Personal/social services, counseling, wellness

### 3. Distinctiveness assessment

| Mark | Distinctiveness | Strength |
| --- | --- | --- |

| Baseline Design | Suggestive (descriptive words in non-descriptive context) | Medium |
| Expression Field | Arbitrary (unusual combination) | Strong |

## Filing strategy

### US filing (USPTO)

| Step | Action | Timeline |
| --- | --- | --- |
| 1 | Conduct trademark search | Before filing |
| 2 | File Intent-to-Use (ITU) application | Before public launch if possible |
| 3 | Respond to Office Actions | Within 6 months |
| 4 | File Statement of Use | Within 6 months of Notice of Allowance |
| 5 | Maintain registration | Sections 8 & 15 at years 5-6; Section 8 + renewal at year 10 |

**Estimated cost**: $250–$350 per class (TEAS Plus/TEAS RF) × 3 classes = $750–$1,050 per mark

### EU filing (EUIPO)

| Step | Action | Timeline |
| --- | --- | --- |
| 1 | Conduct EUIPO search | Before filing |
| 2 | File EUTM application | After US filing |
| 3 | Respond to objections | Within 2 months |
| 4 | Maintain registration | Renew every 10 years |

**Estimated cost**: €850 for first class, €50 for each additional class

### International considerations

| Jurisdiction | System | Notes |
| --- | --- | --- |
| UK | UK IPO | File separately post-Brexit; can claim priority from EUTM |
| Canada | CIPO | File if Canadian users expected |
| Madrid Protocol | WIPO | International registration based on US/EU filing |

## Enforcement strategy

### Monitoring

| Activity | Frequency | Method |
| --- | --- | --- |
| USPTO TESS monitoring | Monthly | Search for confusingly similar new applications |
| EUIPO monitoring | Monthly | Same |
| Domain monitoring | Quarterly | Check for sovereign-os variants |
| App store monitoring | Quarterly | Check for confusing apps |
| Web monitoring | Quarterly | Search for mark misuse |

### Enforcement actions

| Scenario | Action |
| --- | --- |
| Confusing trademark application filed | Oppose during publication period |
| Cybersquatting | UDRP complaint |
| Counterfeit/fake app | DMCA takedown + platform report |
| Competitor using similar mark | Cease and desist; negotiate if warranted |
| Non-competing use | Monitor; no action needed unless confusion arises |

### TM symbol usage

| Symbol | When to use |
| --- | --- |
| TM | Immediately — asserts common law rights |
| SM | Immediately for service marks |
| (R) | Only after registration is granted |

**Recommendation**: Begin using "Sovereign.OS™" on all public surfaces immediately.
